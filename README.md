# Task Manager - Full Stack

A full stack task manager application with authentication and task management.

## Features

- User registration
- User login with JWT authentication
- Create tasks
- Update tasks
- Delete tasks
- Mark tasks as completed
- Task statistics dashboard

## Technologies

### Backend
- Node.js
- Express
- PostgreSQL
- Prisma ORM
- JWT Authentication

### Frontend
- React
- JavaScript
- CSS
